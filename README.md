Huduma Chap Chap

Huduma Chap Chap is an online service-request platform designed to help customers in Kenya access and track assistance with online services.

Features

- Client registration and login
- Client dashboard
- Service listings and pricing in Kenyan shillings (KSh)
- Service-request submission and status tracking
- Administrative dashboard for authorized administrators
- Payment and transaction history
- Planned M-Pesa payment integration
- Referral feature

Technology

The project is intended to use:

- Node.js
- Express
- PostgreSQL
- HTML, CSS and JavaScript

The final technology stack depends on the generated application code.

Setup

1. Clone or download the repository.
2. Install the required dependencies using "npm install".
3. Configure the required environment variables using a local ".env" file.
4. Ensure PostgreSQL is configured if the application requires it.
5. Start the application using "npm start", if the package scripts support this command.

Security

- Never commit passwords, API keys, database credentials or production secrets.
- Restrict administrative access to authorized users.
- Verify payment transactions on the server before updating account balances.

Deployment

The application is intended to be deployed using Render. Configure the required environment variables and database connection before deploying.

Service Disclaimer

Huduma Chap Chap provides assistance with online service requests. Government approvals and medical decisions remain subject to the relevant authorities and qualified providers.
